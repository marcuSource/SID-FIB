# PRACTICA 3 - SID

## Requisits i dependències

### Python
- Python 3.8 fins a 3.11 (a partir del 3.12 l'entorn POGEMA no té support)

### Llibreries Python necessàries
Instal·la les dependències amb:
```bash
pip install -r requirements.txt
```

## Execució dels experiments

### Opció 1: Menú interactiu (recomanat)
Executa el menú principal per llançar tots els experiments o un de concret:
```bash
python PRACTICA3.py
```

## Notes
- El programa genera totes les gràfiques i taules de resultats de forma automàtica.
- Consulta el PDF per a l'anàlisi i conclusions dels experiments.
- Tots els resultats es guardaran en directoris per a cada un dels experiments.
